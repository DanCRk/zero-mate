# ZeroMate v0.4.0-alpha.1

### Better
- **YoRHa Ho229 Type-B Flight Unit Cinematic Intro (`slotFlightUnitIntro`).** 2B arrives on desktop through an authentic NieR:Automata orbital launch sequence:
  - **YoRHa Orbital Bunker Catapult Launch:** Telemetry displays the orbital station and catapult bay countdown before release.
  - **Atmospheric Jet Entry:** High-speed re-entry in Jet Mode with shockwaves, screen shake, sonic booms, and atmospheric particle trails.
  - **Humanoid Mech Transformation:** Mid-air aerodynamic braking, sweeping across the screen, hovering over the ground with retro-thrusters, and an acrobatic disembark jump.
- **YoRHa Ho229 Flight Unit Tactical Retreat (`slotFlightUnitRetreat`).** 2B calls her flight unit for extraction:
  - **Empty Cockpit Mech Descent:** The Ho229 descends in humanoid mech mode showing an empty cockpit with visible harness, joysticks, and avionics without duplicate 2B sprites.
  - **Seamless Boarding:** 2B leaps into the cockpit, the unit transitions to occupied mode, canopy locks shut, and thrusters blast off into orbit.
- **Dedicated Empty Cockpit Sprite (`flight-unit-mech-empty.png`).** Generated from official references and integrated into the chroma pipeline and rendering chain (`prepare-assets.js`, `app.js`, `theme-engine.js`, `fx.js`).
- **Interactive Showcase Expansion (`npm run demo`).** Added `--stage intro` and `--stage retreat` to test and demonstrate the cinematic flight sequences on demand.
- **Windows Native Launcher Recompiled.** Updated `ZeroMate.exe` with latest embedded assets and branding.

### Install (Windows)
- Download `ZeroMate-Setup-0.4.0-alpha.1.exe` below and run it (it seamlessly updates previous versions).
- The installer isn't signed with an expensive enterprise certificate: if Windows SmartScreen says *"Windows protected your PC"*, click **More info** › **Run anyway**.
- Already plugged her into Claude Code or Antigravity? Nothing to redo, hooks and brains update automatically.

### Resumen de los cambios realizados

1. **Sprite de Cabina Vacía (`flight-unit-mech-empty.png`)**:
   - Generado a partir de las referencias oficiales con fondo chroma verde e integrado en el pipeline de assets (`prepare-assets.js`).
   - Muestra el arnés ergonómico, las palancas y la consola de mandos sin ningún ocupante.

2. **Corrección en la Cadena de Renderizado**:
   - **`app.js`**: Se agregó `flightMechEmptyImg` al objeto de imágenes pasado al inicializar `ThemeEngine`.
   - **`theme-engine.js`**: Se pasó `mechEmptyImg` al método de retirada `slotFlightUnitRetreat`.
   - **`fx.js`**: En el Acto 1 de la retirada (`flight_unit_retreat`), la nave que desciende y flota sobre 2B ahora dibuja activamente el sprite con cabina vacía. Al saltar 2B dentro (`boarded = true`), cambia al sprite ocupado, se sella y despega.

3. **Cinemáticas de Unidad de Vuelo YoRHa Ho229 Tipo-B**:
   - **Secuencia de Entrada (`slotFlightUnitIntro`)**: Lanzamiento orbital desde la catapulta del Búnker, descenso a velocidad terminal en modo jet con estelas atmosféricas y temblor de pantalla, frenado aerodinámico, transformación a mech humanoide y desembarco acrobático de 2B en el escritorio.
   - **Secuencia de Retirada (`slotFlightUnitRetreat`)**: Solicitud de extracción táctica, descenso del mech con cabina vacía, salto de abordaje, sellado de compuerta e ignición de propulsores hacia el Búnker orbital.

4. **Verificación y Recompilación**:
   - Probado en vivo con `npm run demo -- --stage retreat` y `npm run demo -- --stage intro`.
   - Lanzador nativo de Windows `ZeroMate.exe` recompilado.
   - Commit integrado en la rama `develop`.
