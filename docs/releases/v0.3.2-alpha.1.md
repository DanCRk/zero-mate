# ZeroMate v0.3.2-alpha.1

### Better
- **Local Push-to-Talk Voice Commands (Whisper STT).** Control 2B and Pod 042 completely by voice with 100% offline local processing. Powered by quantized Whisper-tiny ONNX (`q8` on CPU) with zero cloud token cost, plus native Windows `System.Speech` offline fallback. Toggle anytime with global shortcut `Ctrl+Space` or via the YoRHa command bar `[MIC]` button.
- **Autonomous Agentic Self-Learning & Memory.** The agent now exhibits true tactical autonomy:
  - **Contextual Deduction:** Requests like *"open YouTube with music"* or *"play lofi"* are autonomously deduced into direct search URLs (`https://www.youtube.com/results?search_query=...`).
  - **Persistent User Memory (`skills/user-memory.ctx`):** Remembers preferences, favorite genres, aliases, and project facts across sessions (e.g. asking *"play my favorite music"* recalls previously recorded preferences).
  - **Multi-Tool Execution:** Supports chaining multiple tool actions in a single turn (e.g. opening media while registering preference in memory).
  - **Progressive Skills Catalog:** Dynamically creates, saves, and indexes reusable tactical routines into `skills/INDEX.ctx`.
- **Antigravity CLI (AGY) Model Selection & Lightweight Defaults.** AGY sessions now default to `gemini-3.8-flash-low` with `--effort low`, delivering near-instant responses while protecting your high-tier model quotas. Full model picker added to the YoRHa Brain modal.
- **Universal PC & Browser Target Resolution.** Enhanced natural language intent resolution for default web browsers, direct YouTube/Google queries, system folders (Downloads, Documents, Desktop, Pictures, Recycle Bin), media keys (volume up/down, mute, play/pause), and process management.
- **Dialogue Shielding & Hook Isolation.** Added top priority (`reply: 5`) so assistant answers are never abruptly cut off or overwritten by victory somersaults or IDE completion hooks. Internal CLI calls are fully isolated (`ZEROMATE_INTERNAL: '1'`) to eliminate hook recursion.
- **Dedicated Inverted Ceiling Hang Sprite.** True upside-down suspension when hanging from the upper screen bezel, featuring natural downward drape for 2B's Gothic skirt and hair, top-border boot anchoring, and smooth physics fall.

### Install (Windows)
- Download `ZeroMate-Setup-0.3.2-alpha.1.exe` below and run it (it seamlessly updates previous versions).
- The installer isn't signed with an expensive enterprise certificate: if Windows SmartScreen says *"Windows protected your PC"*, click **More info** › **Run anyway**.
- Already plugged her into Claude Code or Antigravity? Nothing to redo, hooks and brains update automatically.

### Mejor
- **Comandos de Voz Locales Push-to-Talk (Whisper STT).** Controla a 2B y Pod 042 mediante voz con procesamiento 100% local en tu PC. Impulsado por Whisper-tiny ONNX cuantizado (`q8` en CPU) con 0 consumo de tokens en la nube, y fallback nativo sin conexión a `System.Speech` de Windows. Actívalo en cualquier momento con el atajo global `Ctrl+Espacio` o pulsando el botón `[MIC]` en la barra de comandos YoRHa.
- **Auto-Aprendizaje Agéntico Autónomo y Memoria Persistente.** El agente ahora opera con verdadera autonomía táctica:
  - **Deducción Contextual:** Solicitudes abiertas como *"abre youtube con música"* o *"pon lofi"* son analizadas por la IA para generar URLs directas (`https://www.youtube.com/results?search_query=...`).
  - **Memoria de Usuario Persistente (`skills/user-memory.ctx`):** Aprende y recuerda gustos, géneros musicales preferidos, proyectos y apodos entre sesiones (ej. pedir *"abre youtube con mi música favorita"* consulta los registros de memoria aprendidos).
  - **Ejecución Multi-Herramienta:** Permite encadenar varias acciones tácticas en un mismo turno (abrir aplicaciones y registrar en memoria a la vez).
  - **Catálogo de Habilidades Progresivas:** Capacidad de crear, guardar e indexar nuevas rutinas genéricas en `skills/INDEX.ctx`.
- **Selector de Modelos para Antigravity CLI (AGY) y Default Ligero.** Las sesiones de AGY ahora usan por defecto `gemini-3.8-flash-low` con `--effort low`, ofreciendo respuestas inmediatas y protegiendo tu cuota de modelos Pro. Selector interactivo con autocompletado en el modal de Cerebros YoRHa.
- **Resolución Universal de Objetivos y Navegadores.** Reconocimiento fluido en lenguaje natural para abrir tu navegador predeterminado de Windows, realizar búsquedas directas en YouTube/Google, navegar a carpetas del sistema (Descargas, Documentos, Escritorio, Imágenes, Papelera), controles de volumen/música y cierre de procesos.
- **Blindaje de Diálogos y Aislamiento de Hooks.** Asignada prioridad máxima (`reply: 5`) para que las respuestas del asistente nunca sean borradas o pisoteadas por animaciones de victoria o eventos de hooks de la terminal. Aislamiento de procesos (`ZEROMATE_INTERNAL: '1'`) para eliminar bucles de eventos.
- **Sprite Dedicado de 2B Colgada de Cabeza.** Suspensión real boca abajo en el marco superior de la pantalla, con caída natural de falda gótica y cabello plateado por gravedad, botas ancladas arriba y transición suave de caída al soltarse.
