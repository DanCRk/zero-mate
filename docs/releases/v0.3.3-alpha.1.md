# ZeroMate v0.3.3-alpha.1

### Better
- **Overhauled Window Ledge Sitting Physics (`sit_window`).** Restored and polished desktop window sitting:
  - **Relaxed Geometry & Height Margin:** Replaced the rigid screen-top threshold with a forgiving `y >= 20` boundary and dynamic width threshold (`>= 200px`), allowing 2B to comfortably sit on open windows whose title bars reside in the upper area of the monitor.
  - **Z-Order & Occlusion Precision:** The active foreground window (`fg`) is now permanently exempt from false occlusion. Background overlay detection now respects Windows `EnumWindows` top-down order and filters out full-screen desktop containers.
  - **Tactile Drag-and-Drop Tolerance:** Expanded drop snapping distance to `Math.max(50, 68 * scale)` (~50–68px), making it effortless to drop 2B onto any window title bar without her falling past the ledge.
  - **Informative Tactical Dialogue:** Pod 042 explicitly reports if no compatible desktop windows are available rather than gliding to the floor silently.
- **Cinematic Visor Calibration FX (`adjust_visor`).** Made the combat visor adjustment deeply expressive and visually striking:
  - **Pose & Arm Mask Refinement:** Re-engineered keyframe bone rotations in `acting.js` with stoic head tilts and realistic arm raising (`armL: 0.65`) that remains strictly within 2D texture mask bounds, eliminating arm clipping.
  - **High-Tech YoRHa Optic Glint & HUD Lens Gleam:** Added a dedicated canvas FX featuring a horizontal glowing optic scanline (cyan/gold/white gradient), tactical micro-brackets `[ - - ]`, a spinning 4-point diamond star lens flare with anamorphic horizontal glare streak, and `OPTIC // CALIBRATED` telemetry.
  - **Anime Cut-in Banner & NieR Audio:** Accompanied by authentic `pod-scan` and high-pitch `ui-open` optic calibration chirps, along with the dramatic YoRHa combat visor eyes cut-in (`cutin.eyes`).
- **Interactive Lifecycle Hook & Animation Showcase (`npm run demo`).** Rebuilt the showcase script from the ground up:
  - **Direct Action Slot Dispatching:** Added first-class `POST /slot` and `POST /action` endpoints to the local HTTP bridge (`127.0.0.1:47824`), enabling external CLI automation to directly trigger any 2B animation slot.
  - **17-Stage Complete Showcase:** Covers all animations and hooks including Katana Inspection, Visor Calibration, Window Sitting, Pod Petting, Laser Scan, Red Alert Permission Modal, Poke Annoyance Slash, Wall Jump Glide, Window Breach Hacking, Ceiling Hang, Bunker Satellite Uplink, and the Epic Victory Somersault.
  - **Granular CLI Execution:** Run specific animations on demand via `npm run demo -- --stage <name>` (e.g. `npm run demo -- --stage visor`, `--stage sit`, `--stage katana`, `--stage wall_jump`, `--stage alert`, `--stage victory`).
  - **Forced Live Audio:** Mode demo guarantees audible sound effects (`forceAudio: true`) regardless of passive terminal mute settings.
- **Official YoRHa Emblem Desktop & Installer Icon.** Integrated high-resolution multi-size `yorha.ico` across the executable launcher, NSIS installer, and Windows taskbar branding.

### Install (Windows)
- Download `ZeroMate-Setup-0.3.3-alpha.1.exe` below and run it (it seamlessly updates previous versions).
- The installer isn't signed with an expensive enterprise certificate: if Windows SmartScreen says *"Windows protected your PC"*, click **More info** › **Run anyway**.
- Already plugged her into Claude Code or Antigravity? Nothing to redo, hooks and brains update automatically.

### Mejor
- **Física y Anclaje Renovado para Sentarse en Ventanas (`sit_window`).** Restaurada y perfeccionada la capacidad de sentarse sobre las ventanas del escritorio:
  - **Márgenes de Geometría Flexibles:** Se eliminó la restricción rígida que bloqueaba ventanas en los primeros 200px de la pantalla; ahora admite cualquier ventana desde `y >= 20` y ancho >= 200px, permitiendo anclarse en navegadores, editores y terminales habituales.
  - **Precisión de Oclusión y Z-Order:** La ventana activa en primer plano (`fg`) nunca se considera cubierta falsamente, se respeta el orden Z-order de Windows y se descartan contenedores transparentes de pantalla completa.
  - **Tolerancia de Arrastre Táctil:** Margen de soltado ampliado a `Math.max(50, 68 * scale)` (~50–68px), permitiendo arrastrar y acoplar a 2B suavemente a la barra de título sin que caiga al suelo.
  - **Diálogo Táctico Descriptivo:** Pod 042 notifica explícitamente si no existen ventanas abiertas compatibles en lugar de descender en silencio.
- **Efectos Visuales Cinematográficos de Calibración de Visor (`adjust_visor`).** La animación de ajuste de visor ahora es altamente expresiva y visualmente espectacular:
  - **Refinamiento de Rig y Postura:** Nuevos keyframes en `acting.js` con inclinación de cabeza stoica y elevación natural de brazo (`armL: 0.65`) que no clippea la silueta del shader.
  - **Destello Óptico Holográfico y HUD YoRHa:** Nuevo efecto en canvas con escáner horizontal cian/dorado/blanco, micro-corchetes tácticos `[ - - ]`, destello de estrella de 4 puntas giratoria con fulgor anamórfico en el ojo y telemetría `OPTIC // CALIBRATED`.
  - **Banner Anime y Audio NieR:** Sincronizado con pitido digital de escáner táctico (`pod-scan` + `ui-open`) y el banner anime de ojos de 2B (`cutin.eyes`).
- **Showcase Interactivo Completo de Hooks y Animaciones (`npm run demo`).** Reconstrucción integral de la suite de demostración:
  - **Despacho Directo de Semantic Slots:** Nuevos endpoints `POST /slot` y `POST /action` en el puente local HTTP (`127.0.0.1:47824`) para ejecutar cualquier slot de animación directamente desde la consola.
  - **17 Fases y Animaciones Completas:** Demostración de inspección de katana, calibración de visor, asiento en ventana, caricias a Pod 042, escaneo láser, modal de alerta roja, corte relámpago con katana, salto acrobático en pared, brecha de hackeo, suspensión en techo, enlace con el Búnker y gran final de victoria.
  - **Ejecución Granular por CLI:** Dispara cualquier fase individual con `npm run demo -- --stage <nombre>` (ej. `npm run demo -- --stage visor`, `--stage sit`, `--stage katana`, `--stage wall_jump`, `--stage alert`, `--stage victory`).
  - **Audio Forzado en Vivo:** El demo garantiza reproducción de SFX (`forceAudio: true`) sin importar si la terminal pasiva está silenciada.
- **Ícono Oficial del Emblema YoRHa.** Actualizado el ícono del ejecutable, instalador NSIS y barra de tareas con el emblema de YoRHa en alta resolución (`yorha.ico`).
